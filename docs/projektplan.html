GEO-Text-Optimizer

01

Worum es geht

Texte, die für klassisches SEO gebaut wurden, tauchen in KI-Antworten oft nicht auf. Die Studie Generative Engine Optimization (KDD 2024) hat gemessen, was die Zitierwahrscheinlichkeit tatsächlich verändert — und was nicht.

+34 %Quellen nennen
+32 %Statistiken ergänzen
+30 %Zitate einbauen
−10 %Keyword-Stuffing

Keyword-Dichte — der klassische SEO-Hebel — hatte praktisch keinen Einfluss. Was zählt, sind Signale epistemischer Autorität. Genau daraus besteht das Regelwerk in Abschnitt 2.

Die wichtigste Festlegung

Das Werkzeug ergänzt Belege nicht selbst. Die drei stärksten Hebel verlangen Quellen, Zahlen und Zitate — ein Werkzeug, das sie automatisch „erfüllt", erfindet sie. Fehlen sie, entsteht stattdessen eine Rückfrage an den Autor.

02

Das Regelwerk

Zwölf Regeln, jede mit Quelle und Evidenzstärke. Jede Änderung im fertigen Werkzeug verweist auf genau eine Regel-ID — ohne gültige ID keine Änderung. Bei mittlerer oder schwacher Evidenz muss die Begründung das benennen.

Wenn etwas fehlt

Fehlt eine Grundlage, erscheint sie als Lücke mit konkreter Rückfrage: keine Zahl im Text, keine Quelle, kein Zitat, kein Datum, unklare Hauptentität, Zielfrage unbeantwortet, unbelegter Superlativ.

03

Architektur

Fünf Schritte pro Analyse, davon genau ein Modellaufruf. Die deterministischen Schritte messen im Code, was sonst das Modell zählen müsste — das ist der eigentliche Hebel für niedrige Kosten, nicht das Kürzen von Prompts.

1 · Security Gate

Größenlimit, Schema-Prüfung, Rate-Limit, Injection-Scan, Unicode-Normalisierung.

0 Token

2 · Deterministische Analyse

Misst Zahlen, Quellen, Zitate, Absatzlängen, Lesbarkeit, Keyword-Dichte. Ergebnis: Signal-Digest.

≤ 300 Token

3 · Grounding

Eine Suchanfrage, höchstens 5 Treffer, 24-Stunden-Cache je Zielfrage. Zweite Analyse zum selben Thema kostet nichts.

≤ 400 Token

4 · Modellaufruf

Claude Sonnet, erzwungenes Antwortschema. Regelwerk im gecachten System-Prompt, Text und Digests als Daten.

1 Aufruf

5 · Nachprüfung

Schema, Fakten-Wächter, Diff gegen das Original, Score neu berechnen, Ausgabe escapen.

0 Token
Fakten-Wächter

Jede Zahl, jedes Datum, jeder Eigenname und jede URL im Ausgabetext muss im Eingabetext oder in den Suchergebnissen belegbar sein. Andernfalls wird die Stelle markiert.

Ohne diese Sperre wäre ein Werkzeug, dessen wirksamste Regel „ergänze Statistiken" heißt, eine Halluzinationsmaschine mit Abmahnrisiko.

Ausgabe: vier Bereiche

#BereichFelder je Eintrag
1Optimierter TextErsatztext mit markierten Änderungen
2Änderungenvorher, nachher, regel_id, begruendung, impact

Dazu ein GEO-Score vorher und nachher — im Code berechnet, nicht vom Modell geschätzt.

04

Was der Betrieb kostet

Gerechnet für einen Text an der Längengrenze von 25.000 Zeichen, was im Deutschen rund 8.300 Token entspricht.

PositionTokenKosten
Eingabe — Text, Regelwerk, Digests10.7000,021 €
Ausgabe — Text und drei Listen10.3000,103 €
Je Maximal-Analyse21.000≈ 0,12 €

Die Ausgabe ist der Kostentreiber — beim verwendeten Modell ist sie das Fünffache der Eingabe wert. Wer sparen will, begrenzt die Ausgabelänge, nicht den System-Prompt. Beim angenommenen Tagesdeckel von 5 € sind das rund 40 Analysen dieser Größe pro Tag.

Einordnung der Prozentwerte

Die Werte in Gruppe A sind Maximalwerte aus einer Laborstudie — 2023/24, englischsprachig, mit wenigen konkurrierenden Quellen. Kein Durchschnitt, keine Garantie.

Die Richtung — Autoritätssignale schlagen Keyword-Dichte — ist durch GEO-16 unabhängig bestätigt. Die exakten Werte sind es nicht. Deshalb trägt jede Regel eine Evidenzstärke, und das Werkzeug behauptet nie mehr, als die Quelle hergibt.

Dieses Dokument ist die Übersicht. Verbindlich sind die Dateien im Repository: geo-rules.md für die SEO-Logik, spec.md für die Anforderungen, tasks.md für die Umsetzung, prompts/spec-kickoff.md für den Startprompt.

Das Regelwerk wird zur Laufzeit als System-Prompt geladen — eine Änderung darin ändert das Verhalten des Werkzeugs, ohne dass Code angefasst wird.
